# たんぼる 要件定義書（2026-10-24 時点）

## 1. 概要
- サービス名：たんぼる
- ひとこと：だれかといっしょに集中すると、タスクも仲間も田んぼも育つ
- 対象：大学新入生（想定：慶應義塾 湘南藤沢キャンパス＝SFC）
- ペルソナ：田中ハク（18歳・大学1年・地方出身・初めての一人暮らし）
- 解決したいこと
  - 新生活でやることが多く、一人だと続かない
  - 知り合いが少なく、いっしょにがんばれる人がいない
- 解決のしかた
  - 「作業場」で、だれかと同じ時間に集中する
  - 集中とタスク完了でポイントがたまり、田んぼの稲が育つ
  - いっしょに集中した人とは、つながりマップで水路がつながる
- 提供形態：スマホ向け Web アプリ（ホーム画面に追加できる）
- 公開 URL：https://tanboru.vercel.app（noindex、リンクを知っている人だけ）

## 2. 利用の流れ（フェーズ）
| フェーズ | すること | 主な画面 |
|---|---|---|
| 0 はじめる | はじめる → ログイン（ダミーの ID が入っている）→ ホーム | はじめる・ログイン |
| 1 タスクを植える | やること・授業/カテゴリー・締切を登録 | ホーム・タスク |
| 2 作業場で集中 | 作業場をつくる、または人の作業場に入る → 集中 → 終了 | 仲間（作業場） |
| 3 つながる | いっしょに集中した人が水路でつながる。仲間に追加する | 仲間（つながりマップ） |
| 4 実る | 300 pt で収穫 → お米 → 図鑑の料理。カレンダーでがんばりレポートを見返す | マイページ・図鑑・タスク |

## 3. 画面と機能

### 3.1 はじめる・ログイン
- はじめる画面：ロゴ・コピー「だれかといっしょに、今日の一歩。」・「はじめる」
- ログイン画面：ダミーの ID（tanaka.haku）とパスワードが最初から入っている。「ログイン」でホームへ
- 一度ログインすると、次からは直接ホーム。設定の「ログアウト」で戻せる

### 3.2 ホーム（みんなで育てよう）
- 田んぼのイラスト。稲は 60 pt ごとに6段階で育つ
- 空は SFC の今の天気と時間帯で変わる（夜・晴れ・雨）。左上に「SFC 雨 16℃」
- ときどきカラスやイナゴが田んぼに来る
- 進み具合のカード：段階名・「120 / 300 pt」・バー。300 pt で「実りを収穫する」
- 「みんなと集中する」の帯：今集中している人の顔と「N人が集中しています」。押すと作業場へ
  - 集中しているときは「25:00 あなたの作業場で集中」
- 今日のタスク：件数（完了 / 全部）、＋で追加、チェックで完了、ページ送り

### 3.3 タスク（今日のやること）
- 月のカレンダー
  - 今日は緑の塗り、記録のある日は薄緑、選んだ日は黄色
  - ‹ › で月を移動。下メニューのカレンダーか「M月D日のタスク」を押すと、選んだ日の月に戻る
- 選んだ日のタスク一覧・＋で追加・ページ送り
- タスク名を押すと編集画面。削除は編集画面の下の「このタスクを削除」から（確認あり）
- 「がんばりレポート」：その日の集中分・完了件数・写真枚数と、写真・記録の一覧

### 3.4 仲間（作業場タブ・仲間タブ）
- 作業場タブ：いっしょに集中しよう
  - 「作業場をつくる ＋」のバー
  - いま集中している作業場の一覧：顔・だれの作業場・場所・残り時間・人数「1 / 4」
- 仲間タブ：なかまとつながろう（つながりマップ）

### 3.5 作業場
- つくる（ポップアップ）
  - 項目：取り組むタスク・場所（SFC の建物名、またはオンライン）・目印・人数・時間 → ▶ ではじめる
    - 目印は、現地のときだけ入力する
    - 人数は 2 / 4 / 6人、または「その他」で 2〜10人
    - 時間は 15 / 25 / 50分、または「その他」で 1〜180分
  - 選んだ人数まで、場所に合う人から順に約20秒おきに入ってくる（お試し用の演出）
    - 現地：「向かっています」→「着きました」
    - オンライン：「もうすぐ」→「オンラインで入りました」
- 入る
  - 作業場を押すと詳細が開く：種類・残り時間・会の名前・場所・目印・メンバー
  - 取り組むタスクを選んで「ここで合流して集中する」（オンラインなら「オンラインで参加する」）
  - 入れないときは理由を出す（残り3分未満・満員・いま集中していない）
- 集中中
  - タイマー・取り組むタスク・メンバーの顔・「いまの人数 / 定員」
  - スタンプ（がんばろう・いいね・あと少し・おつかれ）、顔を押すと拍手。相手からも届く
  - 時間がたつほど稲のイラストがのびる
  - 人の作業場（現地）では「着いた」を知らせられる
- 終了
  - 「みんなで N分、やりきった！」・ポイント・新しく会った人を仲間に追加・写真を残す・タスクを完了にする
  - 途中で出るときは確認を出す（「最後までなら +N pt／いま出ると +M pt」）

### 3.6 つながりマップ
- 真ん中の「あなた」から、いっしょに集中した人へ水路がのびる
  - 最大6人まで表示し、それより多いときは「ほか N人」
  - 仲間は曲がった水路、まだ仲間でない人は薄い直線の水路
  - 顔の横に回数バッジ「3回」、右上に仲間の人数
- 人を押すと下にカード
  - 名前・学年・「いっしょに3回・75分 ›」（押すとその人との記録）
  - その人が集中中なら「いっしょに集中」
  - まだ仲間でなければ「仲間に追加」（黄色のボタン）

### 3.7 マイページ
- プロフィール：アバター（4種類）・名前・大学・学年・学部（総合政策・環境情報・看護医療）。鉛筆で編集
- 数字（緑）：集中時間・完了したタスク・いっしょに集中した人数
- 収穫・図鑑（薄い黄色の行）・使い方（4ステップ）・設定
- 設定の中身
  - 終わりの合図：振動・音・画面を閉じていても通知
  - タスク：完了したタスクを隠す
  - ログアウト

### 3.8 写真・がんばりレポート
- 作業場の終了画面から写真を残す
  - アプリ内のカメラ：たんぼるのカメラ枠を重ねて撮り、900×1200 の JPEG にする
  - カメラが使えないときはアルバムから選ぶ
- 写真はスマホの中に保存し、カレンダーのがんばりレポートで見返す・消す

### 3.9 収穫・図鑑
- 300 pt で収穫するとお米3カップ
- 図鑑はお米の量で解放：おにぎり3 / カレー6 / オムライス9カップ。「コレクション N / 3」

## 4. ポイント
| できごと | ポイント |
|---|---|
| タスクを完了 | +20 pt |
| 作業場で最後まで集中 | +分数 × 2 pt |
| だれかといっしょに最後まで | さらに +10 pt |
| 作業場を途中で出る | +分数 × 1 pt（ボーナスなし） |
| 収穫 | 300 pt → お米3カップ |

## 5. データ
- スマホのブラウザに保存する
  - localStorage `tanboru-v1`：タスク・ポイント・仲間・記録・設定・プロフィール
  - IndexedDB `tanboru-photos`：写真
- いっしょに集中した記録は最新120件まで

## 6. 外部サービス
- Open-Meteo：SFC の今の天気（登録・キー不要、30分ごと）
- Adobe Fonts：ページのタイトル（AB-j_gu）
- Vercel：公開

## 7. 非機能要件
- スマホ前提。iPhone Safari の見える高さ約630px でもスクロールなしで使える
- 変更のたびに、スマホ幅3サイズ（375×630・390×630・375×812）で次を自動チェックする
  - 1行のはずの文字の折り返し・はみ出し
  - 下メニューとの重なり・近すぎ
- 入力欄の文字は16px（iPhone の自動拡大を防ぐ）。入力中は画面を描き直さない
- iPhone のセーフエリアに対応
- 検索エンジンに載せない（noindex）

## 8. お試し用の部分（本物ではない）
- ログイン（ダミーの ID とパスワード。本物の認証はない）
- 他のユーザーと作業場のメンバー
  - 登場する人は あや・りく・けん・みお の4人
  - 作業場の時刻と入室はすべて演出
- 最初から入っている仲間（あや3回・りく2回・けん1回、みおはまだ仲間でない）と、ここ6日分の記録
- 毎日「今日まで」に移るお試し用のタスク（完了したものは動かない）
