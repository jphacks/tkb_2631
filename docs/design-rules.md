# たんぼる デザインルール（2026-10-24 時点）

style.css の最後の「デザインルール」ブロックと、その後の追記が基準。

## 色
| 名前 | 色 | 使う場所 |
|---|---|---|
| 本文 --ink | #263c31 | 文字の基本。黄色の上の文字も黒 |
| 補足 --sub | #52634f | 2行目の説明・場所・人数の補足 |
| 薄い --muted | #7b8273 | さらに弱い説明・完了したもの |
| 緑 --green | #188358 | ページタイトル・アイコン・数字・主ボタン（入る・はじめる・保存） |
| 選択 --yellow | #f6cf57 | 選んでいるもの（下メニュー・タブ・チップ・カレンダーの選んだ日）。文字は黒 |
| 濃い黄色 --yellow-strong | #c4860b | 仲間に追加（文字は白） |
| 赤 --red | #c33e34 | 今日まで・削除 |
| 茶 --brown | #6b5a1e | 薄い黄色の上の補足文字・目印 |
| 薄緑の面 --tint | #eef1e3 | 副ボタン・時間/人数のチップ・タブの台・→付きの行・がんばりレポート |
| 帯 --focus-band | #e3efd6 | ホームの「みんなと集中する」 |
| 薄い黄色 | #fff7d6 | マイページの「収穫・図鑑」の行・目印 |

- 今日の日付だけは緑の塗りに白い文字
- 白い文字は濃い色の上だけ（緑・赤・濃い黄色）

## 文字
- 大きさは 14 / 16 / 20 / 24 / 40px の5段階（最小14px）
- 太さは 400（普通）と 700（太字）だけ
- 役割ごとの大きさ
  - ページタイトル：24px（背の低い画面は20px）、AB-j_gu、緑。ホームだけ空の上なので白か濃い緑
  - カードの見出し：16px 太字
  - ダイアログの見出し：20px 太字。作業場の詳細では「〇〇の作業場」と会の名前を同じ20pxで並べる
- 入力欄は16px（iPhone の自動拡大を防ぐ）

## 余白と整列
- 画面の左右は16px。ページタイトルの左＝カードの左
- カードの中の左右も16px（カードの中身は画面の端から32px）
- 右にある丸ボタン・タグ・矢印は、同じカードの中で右端の線をそろえる
- チェックの四角は、見出しと同じ左の線に置く
- アイコンの付いた行（作業場をつくるなど）は、アイコンを左から12pxに置き、文字とチップは左から40pxの同じ線から始める
- 下メニューとの間は8px以上あける

## 部品
- 丸ボタン
  - 見出しの横：42px。主の緑も副の薄緑も同じ大きさ
  - 決定（保存・はじめる）：48px。ポップアップの下の真ん中に置く
  - ページ送り：36px。矢印は文字ではなくアイコンにする
- 角丸：カード・ダイアログは20、行・ボタン・入力欄・タブは12、タグは6、丸ボタン・チップは丸
- 影は2種類だけ
  - カード：0 3px 15px rgba(40,65,35,.055)
  - 小さいもの：0 2px 8px rgba(40,65,35,.05)
- 枠線は使わない（軽い影だけ）
- 文字だけのボタン：通常は緑（やめる・作業場を見る）、弱いものは灰（仲間から外す）、危険は赤（このタスクを削除）
- 下メニュー：緑一色のアイコンだけ（文字なし）。選んでいるページは黄色の丸いピル。マイページは本人のアバター
- 仲間に追加：濃い黄色に「人に＋」のアイコン。人のポップアップでは「仲間に追加」の文字つき、マップと記録では丸アイコンだけ
- 作業場をつくる：緑のバーに、文字が左・＋が右（› は付けない）

## 表示しないもの
- 英字のタイトル・サブタイトル、体験版の表記
- 「集中中」（→「集中しています」「〜で集中」）
- 表に出す鉛筆・ゴミ箱（編集はタスク名を押す、削除は編集画面の中）
- 休憩中の表示、水路を回数で太くすること
- ホームの山・丘・学校・木のイラスト

## 文言
- 「いっしょに」はひらがな
- ポイントは数字と pt の間にスペース（+20 pt・300 pt）
- 仲間になったときは「〜さんと仲間になりました」
- 自分の作業場は「つくる」（作業場をつくる・作業場をつくりました）

## チェック
- 変更のたびに、スマホ幅3サイズ（375×630・390×630・375×812）で全画面とポップアップを回る
- `.claude/mobile-check.js` で、文字の折り返し・はみ出し・下メニューとの重なり／近すぎを確かめる
