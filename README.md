## 製品概要
### 背景(製品開発のきっかけ、課題等）
大学に入ったばかりの新入生は、知り合いが少ないまま課題やレポートに一人で向き合うことになります。とくに地方から出てきて初めて一人暮らしをする学生は、相談できる相手も、一緒に勉強する仲間も見つけにくいのが現状です。
一人だとタスクを後回しにしがちで、がんばっても誰にも見てもらえないため、続ける気持ちを保つのが難しいという課題がありました。

### 製品説明（具体的な製品の説明）
「たんぼる」は、同じ大学の仲間とタスクや集中時間を共有して、田んぼを一緒に育てるタスク管理サービスです。
タスクを完了したり集中タイマーをやり終えたりするとポイントがたまり、田んぼの稲が育ちます。300pt で収穫するとお米が手に入り、お店で買った具材と合わせて料理をつくれます。
スマホで使うことを前提にした Web アプリで、ホーム画面に追加してアプリのように使えます。

### 特長
#### 1. がんばりが田んぼの成長として目に見える
タスク完了で +20pt、集中タイマー完了で「分数×2」pt がたまり、稲が育っていきます。集中中によそ見をして画面から離れるとイナゴが現れ、10秒以内に戻らないと田んぼが荒らされてポイントが減ります。

#### 2. 「作業場」で、いま集中している仲間と一緒にがんばれる
自分の作業場をひらくと、ほかの人の画面にもリアルタイムで表示され、誰でも入って一緒に集中できます。一緒に集中した人は「つながりマップ」に水路でつながり、仲間に追加すると田んぼを一緒に育てられます。

#### 3. 収穫したお米で料理をつくって図鑑を集める
収穫したお米と、ポイントでお店から買った具材を組み合わせて料理をつくれます。おにぎり・カレーライス・オムライス・チャーハンなど全8品があり、つくった料理は図鑑に登録されます。

### 解決出来ること
* 一人では続けにくいタスクや勉強を、ポイントと田んぼの成長で楽しく続けられる
* 知り合いが少ない新入生でも、いま集中している人の作業場に入って一緒に勉強できる
* 集中タイマーで取り組んだ時間がタスクごとに記録され、自分のがんばりを振り返れる

### 今後の展望
* 大学メールでの認証を入れて、同じ大学の学生だけが使えるようにする
* 今は作業場だけをサーバーで共有しているので、ポイントや田んぼも共有し、仲間と本当に同じ田んぼを育てられるようにする
* 仲間への連絡機能をつける
* 具材や新しい料理のイラストを用意する（今は絵文字で仮置き）

### 注力したこと（こだわり等）
* スマホでスクロールしなくても使える、直感的な画面。アイコンやイラストで表せるものは文字を減らした
* 枠線なし・色塗りだけの POP 調イラストで統一した、やわらかい見た目
* ホームの空が現在の天気と時間帯で変わり、田んぼにはときどきカラスやイナゴがやってくる
* 集中タイマーは終了時に振動・音・端末通知で知らせ、集中中は画面が消えないようにした
* 「今日まで」や期限切れのタスクは赤で目立たせ、ホームにまとめて表示する

## 開発技術
### 活用した技術
#### API・データ
* Firebase Cloud Firestore（作業場のリアルタイム共有）
* Open-Meteo API（ホームの空に使う現在の天気）
* localStorage（タスク・ポイントなどユーザーデータの保存）
* Page Visibility API（集中中のよそ見検知）
* Web Notifications API・Vibration API・Web Audio API（集中タイマー終了の合図）
* Screen Wake Lock API（集中中に画面を消さない）

#### フレームワーク・ライブラリ・モジュール
* HTML / CSS / JavaScript（フレームワーク・ビルドなし）
* Firebase JavaScript SDK
* Web App Manifest（ホーム画面への追加）
* Vercel（公開）

#### デバイス
* スマートフォン（iPhone / Android のブラウザ）
* PC のブラウザ

### 独自技術
#### ハッカソンで開発した独自機能・技術
* ポイント → 稲の成長 → 収穫 → 料理づくりへとつながる育成のしくみ（[app.js](app.js)）
* 作業場を Firestore で共有し、入退室がほかの人の画面にもすぐ反映されるしくみ（[share.js](share.js)、commit [544686c](https://github.com/jphacks/tkb_2631/commit/544686c)）
* 集中中に画面から離れるとイナゴが現れる「よそ見検知」（[app.js](app.js)）
* お店で具材を買い、お米と合わせて料理をつくるレシピ機能（commit [52deddd](https://github.com/jphacks/tkb_2631/commit/52deddd), [cb7af59](https://github.com/jphacks/tkb_2631/commit/cb7af59)）
* タスク画面の表示件数を画面の高さに合わせて自動で調整し、小さいスマホでもスクロールせずに使えるようにした
